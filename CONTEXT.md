# OpenRecipe

A private, invite-only recipe library for one household. Recipes arrive either
hand-typed or imported from a URL via an LLM, and are cooked from the phone.

**The interface is Polish; this glossary is English.** These terms name concepts in code,
schema, tickets and conversation. What the user sees is a Polish string in `packages/core/src/copy.ts`.
The two are related by the table at the bottom — a term's Polish label is a rendering
decision, not a rename.

## Language

**Recipe**:
The full record of one cookable thing — its ingredient lines, steps, tips, tags,
servings and image.
_Avoid_: meal, dish, entry

**Ingredient Line**:
One row of the ingredients list: an optional quantity, an optional unit, the item
itself, and an optional note. "2 tbsp butter, melted" is one Ingredient Line, not four
values in a string.
_Avoid_: ingredient (ambiguous — the row or the foodstuff?), item

**Section**:
An optional heading over a run of a Recipe's Ingredient Lines — "Ciasto", "Sos", "Do
podania". A name on the line, not a thing of its own: lines with the same Section sit
together, ungrouped lines come first, and a Section with no lines does not exist.
See ADR-0008.
_Avoid_: component, group, part, subrecipe

**Servings**:
How many portions the Recipe's stored quantities produce. The number the reader picks
on the page is a *display scale* over this, never written back to the Recipe.
_Avoid_: portions, yield, serving size

**Step**:
One instruction in the cooking sequence. Deliberately short — a line, not a paragraph.
_Avoid_: instruction, direction, method

**Tip**:
Advice that isn't part of the sequence — swaps, warnings, storage, what the author
learned the hard way. Lives after the Steps.
_Avoid_: note, hint

**Tag**:
A curated label a Recipe carries, belonging to exactly one Facet. Chosen from a closed
list — never typed freehand. A Recipe carries at most 5, in any mix of Facets.
_Avoid_: category, label, keyword

**Facet**:
A group of Tags that answer the same question: Meal Slot, Cuisine, Diet, Effort, Vibe.
Facets exist so filters can be sectioned and so Proposals can ask for a Meal Slot.
_Avoid_: tag group, tag type, dimension

**Meal Slot**:
The Facet answering "when in the day": breakfast, brunch, lunch, dinner, snack,
dessert, drink, side, sauce. The one Facet with behaviour attached to it.

**Proposal**:
A Recipe the app suggests for one Meal Slot today. Derived, never stored — a Proposal
is a query result seeded by (date, slot, reroll count), not a row.
_Avoid_: suggestion, recommendation, meal plan

**Invite**:
A single-use, expiring token that lets exactly one new person create an account. The
only way an account comes into existence. Minted by the Master and delivered by hand.
_Avoid_: invitation code, signup link

**Master**:
The single owner of the instance, identified by a seeded email. The one role that can
never be granted or taken away; otherwise holds the same powers as an Admin.
_Avoid_: owner, superuser

**Admin**:
A Member the Master or another Admin has promoted. Can do everything the Master can —
edit Recipes, run imports, mint Invites, manage Tags and roles — except demote or
remove the Master.
_Avoid_: moderator, editor

**Member**:
Anyone who joined via an Invite. Read-only unless promoted to Admin: browses and
cooks from Recipes, changes nothing shared — except logging their own Cook Log entries
and using the Shopping List, which is household logistics, not library content.
_Avoid_: guest, invitee, regular user

**Draft**:
A candidate Recipe that is not yet part of the library. Holds the same shape as a Recipe
plus where it came from and how it's getting on. Nothing becomes a Recipe without a human
approving its Draft.
_Avoid_: pending recipe, staged recipe, import

**Source URL**:
The page a Draft was derived from. Kept on the resulting Recipe as provenance.
_Avoid_: origin, link, import URL

**Worker**:
The script on the Master's own machine that turns queued Source URLs into Drafts using
their Claude subscription. The only thing in the system that talks to a model.
_Avoid_: crawler, importer, job runner, agent

**Substitute**:
A stand-in for one Ingredient Line's item, with a one-line note on how it differs.
Generated by the Worker and *stored* — never fetched live, because the kitchen has no
model to ask.
_Avoid_: replacement, alternative, swap

**Pantry Check**:
The reader's ticks against a Recipe's Ingredient Lines, meaning "I already have this".
Lives in the browser only, expires after a day, and belongs to nobody in the database.
_Avoid_: shopping list, checklist state, inventory

**Shopping Export**:
The formatted text of one Recipe's *unticked* Ingredient Lines at the current display
scale, handed to the clipboard or a share target. Single-Recipe and never stored.
_Avoid_: shopping list, grocery list

**Shopping List**:
The household's one shared list of what to buy, built from several Recipes, each at a
chosen serving count. Stored on the server; anyone signed in — Members too — adds
Recipes and ticks items (ADR-0009). Its rows are merged: the same item in the same
unit is summed, the same item in another unit sits beside it, and every row names the
Recipes it came from.
_Avoid_: grocery list, cart, basket, shopping export

**Shopping List Item**:
One merged row of the Shopping List: an item, a unit (or none), a summed quantity (or
none — "do smaku"), and its source Recipes. Ticked when bought; the tick is shared.
_Avoid_: line (that is an Ingredient Line), entry

**Cook Log**:
A record that someone actually made a Recipe on a given day. The only behavioural data in
the system: it feeds the dashboard's counts and keeps Proposals off anything cooked in the
last week.
_Avoid_: history, activity, made-it
